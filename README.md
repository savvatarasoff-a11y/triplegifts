# Бот-двойник для Telegram

Бот отвечает на личные сообщения **от вашего имени и в вашем стиле** через Telegram для бизнеса.
Всё настраивается с телефона: код лежит на GitHub, бот работает на Railway 24/7, а управляется командами в Telegram.

**Как это работает:** собеседник пишет вам → бот видит сообщение через Telegram для бизнеса → Claude пишет ответ в вашем стиле (по вашему описанию, примерам и последним 20 сообщениям чата) → бот присылает вам черновик на проверку или сам отвечает с паузой и статусом «печатает…».

> **Что понадобится**
> - **Telegram Premium**: без него «Telegram для бизнеса» и чат-ботов не подключить.
> - **Аккаунт Railway** (railway.com). Бесплатно дают только пробный кредит, дальше платный тариф (около $5 в месяц; точную цену смотрите на сайте).
> - **Ключ Claude API** (console.anthropic.com). Оплата по использованию, пополнение картой.

## Шаг 1. Создать бота и получить токен (@BotFather)

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и нажмите **Запустить**.
2. Отправьте `/newbot`.
3. Введите имя бота (любое, например «Мой помощник»).
4. Введите username латиницей, он должен заканчиваться на `bot` (например `savva_helper_bot`).
5. BotFather пришлёт **токен** вида `123456789:AAH...`. Скопируйте его: это `BOT_TOKEN`.
6. Там же включите бизнес-режим: `/mybots` → ваш бот → **Bot Settings** → **Business Mode** → **Turn on**.

> Токен — это пароль от бота. Никому его не отправляйте и не вставляйте в код.

## Шаг 2. Узнать свой OWNER_ID (@userinfobot)

1. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите **Запустить**.
2. Бот пришлёт ваш **Id**, это число. Оно и есть `OWNER_ID`.

Ваш ID: **`5349009098`**.

## Шаг 3. Получить ключ Claude API

1. Зайдите с телефона на [console.anthropic.com](https://console.anthropic.com) и зарегистрируйтесь.
2. **Billing**: пополните баланс.
3. **API Keys** → **Create Key** → скопируйте ключ вида `sk-ant-...`. Это `ANTHROPIC_API_KEY`.

## Шаг 4. Запустить бота на Railway

1. Откройте [railway.com](https://railway.com) в браузере телефона → **Login** → **Login with GitHub**.
2. **New Project** → **Deploy from GitHub repo** → выберите репозиторий **bot**.
   Если его нет в списке, нажмите **Configure GitHub App** и дайте Railway доступ к репозиторию.
3. Откройте появившийся сервис → вкладка **Variables** → **New Variable** и добавьте по одной:

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от @BotFather |
   | `ANTHROPIC_API_KEY` | ключ `sk-ant-...` |
   | `OWNER_ID` | `5349009098` |
   | `DB_PATH` | `/data/bot.db` |

   Необязательные переменные:
   * `CLAUDE_MODEL`, по умолчанию `claude-opus-5-5`
   * `OWNER_NAME`, по умолчанию `Савва`
   * `REPLY_DELAY_MIN` и `REPLY_DELAY_MAX`, по умолчанию 5 и 60 секунд
   * `OWNER_PAUSE_MINUTES`, по умолчанию 30

4. **Подключите диск, чтобы база не пропадала при перезапуске.** В проекте нажмите **+ Create** (или **New**) → **Volume** → выберите сервис бота → **Mount path**: `/data`.
5. В настройках сервиса (**Settings** → **Source**) проверьте, что выбрана ветка **main**.
6. Railway соберёт и запустит бота сам. Статус **Active** или **Success** во вкладке **Deployments** значит, что бот работает.
   Логи смотрите в **Deployments** → последний деплой → **View Logs**.

> Каждый новый коммит в `main` Railway разворачивает автоматически. Код можно править прямо на github.com с телефона.

## Шаг 5. Написать боту

Откройте своего бота в Telegram и нажмите **Запустить** (`/start`). Без этого бот не сможет присылать вам черновики и уведомления.
Все команды работают **только** для вашего `OWNER_ID`, остальным бот отвечает, что он личный.

## Шаг 6. Подключить бота в Telegram для бизнеса

1. Telegram → **Настройки** → **Telegram для бизнеса** → **Чат-боты**.
2. Введите username бота (`@..._bot`) и выберите его.
3. **Доступ к чатам**: «Все личные чаты» (можно исключить отдельные) или «Только выбранные».
4. Включите разрешение **отвечать на сообщения**.
5. Бот пришлёт вам «🔌 Бот подключён к аккаунту».

**По умолчанию бот ничего не отправляет сам.** Когда вам кто-то напишет, придёт карточка «Новый чат» с кнопками **✅ Разрешить / 🚫 Блок**. Для разрешённых чатов бот присылает черновик ответа с кнопками **Отправить / Изменить / Пропустить**.

## Шаг 7. Научить бота вашему стилю

Чем больше примеров, тем больше бот похож на вас. Хватит нескольких десятков.

### Описание манеры: `/style`
Отправьте `/style` и следом одним сообщением опишите, как вы пишете. Например:

> пишу коротко, почти всегда с маленькой буквы, без точек в конце. часто «ща», «норм», «го», «хз». из эмодзи 😂 и 🤝. иногда матерюсь с друзьями. часто пишу 2–3 сообщения подряд вместо одного длинного. здороваюсь «прив» или «здарова», прощаюсь «давай»

### Примеры: `/examples`
Отправьте `/examples`, и бот начнёт собирать примеры. Их можно давать тремя способами:

* **Пересылка.** Выделите в любом чате свои сообщения → **Переслать** → выберите бота.
  Чтобы сохранить пару, сначала перешлите сообщение собеседника, а следом свой ответ.
* **Текстом.** Пришлите в таком формате:
  ```
  мне: го гулять?
  я: ща
  через часик
  мне: ок
  я: давай
  ```
  Строки без метки продолжают предыдущую реплику, и каждая такая строка считается отдельным сообщением.
* **Скриншоты.** Пришлите скриншоты переписок, можно несколько сразу. Бот распознает текст и сохранит **ваши** сообщения (справа) с репликами собеседника. В подписи к фото можно дать подсказку, например «я — зелёные сообщения».

Когда закончите, отправьте `/done`: бот пересчитает профиль стиля.

### Профиль: `/profile`
Показывает три вещи: ваше описание; статистику (длину сообщений, заглавные буквы, точки, частые слова, эмодзи, приветствия и прощания, сколько сообщений вы пишете подряд); краткое описание стиля от Claude.
`/profile new` заново составляет описание стиля. `/reset_style` стирает описание и все примеры.

### Обучение на ходу
Если вы сами отвечаете в чате, куда подключён бот, этот ответ сохраняется как пример, а бот **молчит в этом чате 30 минут**.

## Команды

| Команда | Что делает |
|---|---|
| `/on`, `/off` | Включить или выключить автоответы |
| `/draft` | Режим черновиков вкл/выкл (по умолчанию **вкл**); `/draft on`, `/draft off` |
| `/allow` | Разрешить чат: `/allow @username`, `/allow 123456` или без аргумента, чтобы выбрать из списка |
| `/block` | Заблокировать чат |
| `/stats` | Сколько ответов отправлено и в каких чатах |
| `/style` | Описать свою манеру |
| `/examples`, `/done` | Начать и закончить сбор примеров |
| `/profile` | Показать профиль стиля |
| `/reset_style` | Стереть стиль и все примеры |
| `/cancel` | Отменить текущее действие |

## Как бот отвечает

* Режим белого списка: бот отвечает только в чатах, которые вы разрешили.
* Сначала ждёт несколько секунд, не допишет ли собеседник ещё сообщение. Потом Claude пишет ответ по вашему описанию стиля, статистике, 10–15 самым похожим примерам и последним 20 сообщениям чата.
* Если вы обычно пишете несколькими сообщениями подряд, бот тоже разобьёт ответ на части.
* Перед отправкой бот ждёт от 5 до 60 секунд и показывает «печатает…».
* **Если вопрос требует вашего решения** (встречи, деньги, обещания, факты, которых нет в переписке), бот ничего не выдумывает. Он отвечает уклончиво в вашем стиле («ща гляну, отпишу») и присылает вам уведомление «🙋 Нужно твоё решение».
* На сообщения старше 10 минут (например, пришедшие, пока бот перезапускался) бот не отвечает.
* В логах нет токена бота и ключа API: они маскируются.

## Если что-то не работает

* **Бот молчит в личке.** Откройте логи в Railway (**Deployments** → **View Logs**). Сообщение «Не задана переменная окружения …» значит, что переменная не добавлена во **Variables**.
* **Черновики не приходят.** Проверьте четыре вещи: вы нажали `/start` у бота; чат разрешён (`/allow`); автоответы включены (`/on`); в «Чат-ботах» разрешено отвечать на сообщения.
* **`Conflict: terminated by other getUpdates request`.** Запущены две копии бота с одним токеном. Оставьте одну.
* **«Claude: неверный ANTHROPIC_API_KEY» или «модель не найдена».** Проверьте ключ, баланс и переменную `CLAUDE_MODEL`.

## Для разработчика

```
app/
  main.py          точка входа, long polling
  config.py        переменные окружения
  db.py            SQLite (aiosqlite)
  llm.py           Claude: ответ в JSON, скриншоты, описание стиля
  style.py         статистика стиля, подбор примеров (TF-IDF)
  humanize.py      паузы, «печатает…», отправка частями
  responder.py     логика ответов, черновики, обучение на ходу
  handlers/        команды владельца, бизнес-апдейты, кнопки
tests/             pytest
```

Запуск тестов: `pip install -r requirements-dev.txt && pytest -q`. Тесты также прогоняются в GitHub Actions на каждый push.
